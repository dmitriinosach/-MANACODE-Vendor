# [manacode] Vendor 0.1.1

Окно торговца для WoW 3.3.5a: весь товар одним прокручиваемым списком вместо страниц по десять.
Товар разложен по группам — сеты, слоты, подтипы, рецепты, ранги репутации, — поиск понимает
английскую раскладку, у вещи, которая уже есть в сумках, банке или на тебе, стоит галочка.

**Установка**
1. Распакуйте архив в `Interface\AddOns` — должна получиться папка `ManaCode_Vendor`.
2. Полностью перезапустите клиент: `/reload` новую папку не увидит.

**Что умеет**
- Плитка в две колонки или строки, размер окна запоминается у каждого торговца свой.
- Фильтр «что скрывать»: непригодное, чужой класс, чужая профессия, чужие характеристики, не тот класс брони, лишние припасы, старые ранги.
- Покупка пачкой x5, x20, x100 с окном подтверждения: сколько стопок ляжет в сумку и сколько это стоит.
- Цепочка обмена: если торговец меняет одну свою валюту на другую, весь путь до вещи виден и проходится одной кнопкой.
- Цена в золоте и валютах, красная при нехватке; в подсказке — чем платить словами и сколько есть.
- Продажа хлама одной кнопкой, выкуп отдельной вкладкой, починка своими деньгами или гильдии.
- Сравнение с надетым — пока держишь Shift.

Команды: `/vendor` — состояние, `/vendor off` — вернуть штатное окно, `/vendor on` — включить снова,
`/vendor reset` — забыть размеры окон.
